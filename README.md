## 🚀 How to Reflect Updates on GitHub & Vercel (`nobieslens.vercel.app`)

1. Open your repository on [**GitHub.com**](https://github.com).
2. Click **"Add file"** &rarr; **"Upload files"**.
3. Drag and drop:
   - `index.html`
   - `css/` (or `css/style.css`)
   - `js/` (or `js/main.js`)
   - `assets/` (including `nobies-lens-logo.png` and all images)
4. Under **Commit changes**, type: `Update Poppins font, Cream/White theme, custom cursor, logo, and spellings`.
5. Click **"Commit changes"**.

Vercel will detect the update and redeploy your live site at **`nobieslens.vercel.app`** in ~20 seconds!
